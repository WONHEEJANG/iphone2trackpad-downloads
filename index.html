NATURAL CONTROL

트랙패드의 기본에 충실하게

자주 쓰는 조작은 익숙하게, 연결 문제는 눈에 보이게 설계했습니다.

01

정확한 기본 조작

포인터 이동, 좌·우클릭, 더블 클릭, 스크롤과 드래그 앤 드롭을 지원합니다.

02

운영체제 제스처

세 손가락과 네 손가락 스와이프를 각 운영체제의 화면 전환 동작으로 연결합니다.

03

안전한 로컬 연결

같은 Wi-Fi에서 직접 연결하며 Windows는 TLS와 최초 6자리 코드로 페어링합니다.

04

iPhone 키보드 입력

시스템 키보드로 작성한 한글, 영문과 이모지를 컴퓨터의 현재 입력란으로 전송합니다.

05

보이는 연결 상태

연결 상태와 입력 로그를 Receiver에서 확인하고 한 번에 복사할 수 있습니다.

SETUP GUIDE

3분이면 준비됩니다

운영체제를 선택해 설치 순서를 확인하세요.

  1. 1

    다운로드하고 열기

    ZIP 압축을 푼 뒤 TrackpadReceiver를 응용 프로그램 폴더로 옮겨 실행합니다.

  2. 2

    손쉬운 사용 허용

    시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Receiver를 켭니다.

  3. 3

    iPhone에서 연결

    같은 Wi-Fi에 연결하고 iPhone 앱에 나타난 Mac을 선택합니다.

처음 실행이 막히나요?

Finder에서 앱을 Control-클릭한 뒤 열기를 선택하세요. 앱 배포 서명 전 프리뷰에서는 macOS 확인 창이 표시될 수 있습니다.

  1. 1

    압축 풀고 실행

    ZIP 파일 전체의 압축을 푼 뒤 TrackpadReceiver.Windows.exe를 실행합니다.

  2. 2

    네트워크 접근 허용

    Windows 방화벽 알림에서 개인 네트워크 접근을 허용합니다.

  3. 3

    6자리 코드로 연결

    iPhone 앱에서 PC를 선택하고 Receiver 화면의 페어링 코드를 입력합니다.

PC가 보이지 않나요?

Receiver에 표시된 IP 주소를 확인한 뒤 iPhone 앱에서 Windows IP로 직접 연결을 선택하세요.

HELP

자주 묻는 질문

iPhone과 컴퓨터가 서로 보이지 않아요.

두 기기가 같은 Wi-Fi에 연결되어 있는지 확인하세요. 게스트 Wi-Fi처럼 기기 간 통신을 막는 네트워크에서는 자동 검색이 되지 않을 수 있습니다. Windows는 IP 직접 연결도 사용할 수 있습니다.

연결됐는데 커서가 움직이지 않아요.

Mac은 손쉬운 사용 권한을 확인하고, Windows는 Receiver를 조작하려는 앱과 같은 권한 수준으로 실행하세요. Receiver의 로그 복사 버튼으로 진단 내용을 공유할 수 있습니다.

인터넷이 없어도 사용할 수 있나요?

네. iPhone과 컴퓨터가 서로 통신할 수 있는 같은 로컬 네트워크에 있으면 입력 전송에 인터넷은 필요하지 않습니다.

Windows ARM PC에서도 동작하나요?

ARM64 전용 배포 파일을 제공합니다. Snapdragon 기반 Windows PC라면 다운로드 카드의 ARM64 버전을 선택하세요.
